# ทดลองใช้ ITShop

เว็บ demo เปิดให้ดูหน้า Home, หมวดสินค้า ตัวกรอง และรายละเอียดสินค้าได้โดยไม่ต้องเข้าสู่ระบบ

หากต้องการลองตะกร้า คูปอง หรือ checkout ให้สมัครบัญชี User ของตัวเองที่ `/Account/Signup` แล้วเข้าสู่ระบบที่ `/Account/Login` ระบบนี้เป็นโปรเจกต์ทดลองและไม่มีการรับชำระเงินผ่าน payment gateway

บัญชี Admin และ SuperAdmin ใช้สำหรับดูแลข้อมูลหลังบ้าน รหัสทดสอบสำหรับฐานข้อมูล localhost อยู่ใน `TEST-ACCOUNTS.local.md` ที่เก็บเฉพาะในเครื่องและถูก Git ignore หากใช้ฐานข้อมูลอีกชุดในการ deploy ต้องเปลี่ยนรหัสของบัญชีในฐานข้อมูลชุดนั้นด้วย

สำหรับการสร้างบัญชีทดสอบในเครื่องพัฒนา คำสั่ง `--seed-test-accounts` ต้องใช้ environment variable `TestAccounts__Password` และทำงานได้เฉพาะ `Development` เท่านั้น คำสั่งนี้จะรีเซ็ตรหัสของบัญชีทดสอบทั้งสาม จึงไม่ควรรันหลังเปลี่ยนรหัส Admin และ SuperAdmin เว้นแต่ตั้งใจรีเซ็ตอีกครั้ง รหัสผ่านและรายละเอียดบัญชีทดสอบในเครื่องควรเก็บในไฟล์ส่วนตัวที่ไม่ได้ commit
