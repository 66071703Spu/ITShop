# ทดลองใช้ ITShop

เว็บ demo เปิดให้ดูหน้า Home, หมวดสินค้า ตัวกรอง และรายละเอียดสินค้าได้โดยไม่ต้องเข้าสู่ระบบ

หากต้องการลองตะกร้า คูปอง หรือ checkout ให้สมัครบัญชี User ของตัวเองที่ `/Account/Signup` แล้วเข้าสู่ระบบที่ `/Account/Login` ระบบนี้เป็นโปรเจกต์ทดลองและไม่มีการรับชำระเงินผ่าน payment gateway

บัญชี Admin และ SuperAdmin ใช้สำหรับดูแลข้อมูลในเครื่องพัฒนา ไม่เปิดเผยรหัสผ่านบน GitHub หรือในเว็บ demo

สำหรับการสร้างบัญชีทดสอบในเครื่องพัฒนา คำสั่ง `--seed-test-accounts` ต้องใช้ environment variable `TestAccounts__Password` และทำงานได้เฉพาะ `Development` เท่านั้น รหัสผ่านและรายละเอียดบัญชีทดสอบในเครื่องควรเก็บในไฟล์ส่วนตัวที่ไม่ได้ commit

คำอธิบายฟังก์ชันและ flow ของระบบอยู่ใน [README หลัก](README.md)
